# Neovim config

Based on [kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim) at commit `f0a2108`
(vendored, no longer tracks upstream). Plugins are managed by Neovim's built-in `vim.pack`;
`nvim-pack-lock.json` pins their revisions.

Personal configuration lives in `lua/custom/plugins/` (lazygit, neo-tree tweaks, colorscheme,
conform formatters, autoread). `lua/kickstart/plugins/neo-tree.lua` has local edits too.
